https://honeysuckler.fun

Официальный сайт музыкального проекта **хонисаклер**.

## Стек

- HTML
- CSS
- JavaScript
- GitHub Pages
- GitHub Actions
- Python - вспомогательные скрипты для подготовки аудио и архивов
- FFmpeg - конвертация аудио

## Что реализовано

- дискография альбомов и синглов
- встроенный аудиоплеер
- переключение треков и перемотка
- скачивание отдельных треков
- скачивание альбомов архивом
- поддержка релизов с несколькими треками
- адаптивная вёрстка
- собственный домен и HTTPS
